AI Agent 核心公式：
Model ＋ Harness 拆解與實作

從「AI 出一張嘴」到「你出一張嘴」！搞懂模型的大腦思考機制，結合環境、工具與規則手冊，讓 AI 成為為你產出成品的專屬員工。

01
思維轉型

✦ 從「問 AI」到「交辦給 AI」

這不是換一個軟體，而是你在工作現場與 AI 協作模式的根本位移：

評估維度 對話式（Chat 模式） 代理式（Agentic 模式）
你的角色定位 發問者、操作員（人是 AI 的手腳） 老闆、專案經理（你出一張嘴與驗收）
協作過程 一問一答，人類全程緊盯螢幕 交辦後 AI 自主執行多步驟，人可離開
觸及邊界 僅限對話框內的靜態文字輸出 讀寫本機檔案、執行終端機、串接 API
最終產物 一段供參考的回答 一份驗收合格的實際成品（專案代碼、報表）
從今天起：你不是在向顧問請教，而是交辦一件有驗收標準的具體任務。
02
架構核心

✦ 課程核心公式

🤖 AI Agent ＝ 🧠 AI Model (大腦) ＋ 🦺 Harness (工作裝備)
腦

AI Model（思考核心）

大型語言模型本質上只做一件事：預測下一個 Token。它擅長規劃、理解語境、綜合歸納與代碼生成，但它本身「沒有手腳」，無法主動觸摸檔案系統。

手

Harness（行動裝備系統）

負責落地的執行安全網：捕捉模型的工具呼叫，安全執行讀寫、執行測試命令，再將真實反饋送回大腦。模型大家都差不多，決定好不好用的是 Harness！

💡 打造 Agent 的本質：教 AI 用你的標準與 SOP 做事。
03
裝備清單

✦ 一個完整的 Harness 有什麼？

1

💻 工作空間 (Workspace)

沙盒化獨立目錄，讓 Agent 讀寫專屬檔案與執行隔離程式。

2

🧰 執行工具 (Tools)

檔案讀寫、Terminal 命令、網頁爬蟲與搜尋引擎。

3

🔌 連接器 (MCP)

Model Context Protocol，掛載公司內部 ERP、SQL 或 Notion。

4

📘 技能模組 (Skills)

封裝專業領域的標準作業流程（SOP），即插即用。

5

📜 規則手冊 (Handbooks)

AGENTS.md / CLAUDE.md，開工必讀的原則底線與規範。

6

⏰ 自動排程 (Triggers)

Cron 定時或事件 Webhook 驅動，達成無人值守自動化。

📌 其中你唯一能 100% 掌握、影響力最大的，就是那份規則手冊（AGENTS.md）！
04
交辦基本功

✦ 好老闆交辦，講清楚三件事

①

明確的成品 (Deliverable)

做完我會拿到什麼？存放在哪個檔案路徑？檔案結構與格式規範為何？

②

嚴格的限制 (Constraints)

哪些可以動、哪些絕對不能刪？色彩變數是否鎖定？是否需使用全形標點？

③

驗收的規準 (Acceptance)

如何證明你做完了？是否需提供執行計畫？代碼語法測試是否完全過關？

❌ 模糊交辦

「幫我整理企管財務作業資料夾，越快越好。」（AI 只能盲猜，甚至誤刪重要資料）

✅ 代理人交辦

「將 raw/ 整理為結構化 HTML。保留原檔不可刪除，動手前先提大綱，做完運行測試確認 0 錯誤。」

05
企管落地

✦ 企業級應用範例：合約智審特工

在企業管理現場，如何落實 Model ＋ Harness 的威力？

SOP

自動化合約審查閉環

1. 讀取：Agent 透過 File Tool 讀取供應商 PDF 條款草案。
2. 比對：Model 對照公司採購法遵規則庫（Rules）。
3. 產出：輸出紅字風險修訂版與談判建議書。

ROI

企業效益評估指標

• 審約耗時由原本 4 小時縮減至 15 分鐘。
• 藉由 AGENTS.md 統一審查嚴格度，消除法務人為疏漏。
• 全程本地或私有雲端執行，保障商務機密安全。
