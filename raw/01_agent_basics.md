# 原始筆記 01：AI Agent 核心觀念與企業交辦思維

- 來源：國立政治大學 TAICA / DiveAI「換你當老闆！Agentic Work 與 AI 工作現場」講義筆記
- 整理者：Simon (中原 企管系)
- 原始建檔日期：2026-11-03

---

## 1. 核心公式
- 公式：`AI Agent ＝ AI Model（大腦） ＋ Harness（工作裝備）`
- 解釋：
  - AI Model 本質上只會「接下一個字」（Token 預測），它本身不會開檔案、點滑鼠、上網或存檔。
  - Harness（安全帶／韁繩／工作裝備）負責賦予模型「行動的能力」：把模型輸出的指令轉為實際呼叫（讀寫檔案、終端命令、API 呼叫），再將執行結果回傳給模型。

## 2. Harness 的六大關鍵裝備
1. **工作環境（Workspace / Sandbox）**：讓 AI 擁有自己的目錄空間，可獨立建立、編輯與測試檔案。
2. **工具（Tools）**：檔案讀寫、Shell 終端、瀏覽器抓取、網路搜尋。
3. **連接器（MCP / Model Context Protocol）**：讓 AI 連結企業內部資料庫、ERP、CRM、Notion 或雲端硬碟。
4. **技能（Skills）**：特定任務的標準作業流程（SOP），以資料夾與 `SKILL.md` 形式隨需加載。
5. **規則檔（Handbooks: AGENTS.md / CLAUDE.md）**：AI 每次開工前必讀的「員工守則」，定義限制、格式、架構與禁止事項。
6. **排程（Schedules / Triggers）**：定時或事件觸發自動開工。

## 3. 當老闆的交辦三要件
- 糟糕的交辦：「幫我整理桌面」、「幫我寫一個網站」。
- 成功的代理式交辦：
  1. **成品（Deliverables）**：明確指涉產出物放在哪個路徑、什麼檔案格式、具備哪些章節。
  2. **限制（Constraints）**：不准刪除既有檔案、不可動到核心設定、風格配色不得擅自變更。
  3. **驗收（Acceptance Criteria）**：動手前先看計畫、做完後列出異動清單，並通過語法檢查或測試。
