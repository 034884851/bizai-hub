# BizAI Hub - AI Agent 開發規約與員工手冊 (AGENTS.md)

## 一、專案目的與核心願景
本專案為政大企管系「AI Agent 落地實戰知識庫與講義庫」，核心目標是建立一套具備「自我演進、高延展性、標準化模板」的知識傳播體系。

## 二、技術棧規範（零依賴原則）
1. 純原生 HTML5 + Modern CSS + Vanilla JS。
2. 嚴禁引入肥大之外部框架或打包工具，確保在 GitHub Pages 隨推即顯。
3. 中文字型優先使用 Google Fonts (Noto Sans TC + M PLUS Rounded 1c)。

## 三、視覺系統標準（嚴格色票與語意類別）
--cream: #FCF8F0; (主背景)
--navy: #1E3A5F; (標題、框線)
--blue: #5FA8C4; (重點強調)
--blush: #F4B3BE; (手帳腮紅)
--teal: #7CCBC9; (科技薄荷綠)
--yellow: #F7E6A8; (亮點高光)

## 四、頁面類型原型 (Archetypes)
- Type A: Slide Deck (講義簡報頁，支援鍵盤導覽、手帳膠帶)
- Type B: LLM Wiki (概念詞條頁，遵循 Karpathy 三層解耦)
- Type C: Portal Index (大廳總覽頁，具備即時搜尋與計數器)

## 五、AI 擴充標準作業程序 (SOP)
1. 讀取 templates/ 相對應之範本。
2. 執行 python tools/new_content.py 或手動填入語意區塊。
3. 執行 python tools/validate_site.py 驗收無任何報錯與死鏈。
